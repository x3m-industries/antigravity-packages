⚡ Universal Installer CLI Reference

The universal installer script (install.sh) accepts command-line parameters for unattended CI/CD automation, component selection, diagnostic inspection, and clean uninstallation.

Flag Description Privileges
-y, --yes, --non-interactive Run silently without interactive prompts (installs IDE, Hub, CLI) Sudo required
--all Explicitly install all three components (IDE, Hub, CLI) Sudo required
--cli-only Install only the Antigravity CLI (agy) in ~/.local/bin/agy User-Space (No sudo)
--ide-only Install only the Antigravity IDE (code editor) via RPM/DEB Sudo required
--hub-only Install only the Antigravity Hub (agent platform) via RPM/DEB Sudo required
--no-cli Skip Antigravity CLI installation (desktop packages only) Sudo required
--no-ide Skip Antigravity IDE installation Sudo / User
--no-hub Skip Antigravity Hub installation Sudo / User
--status Inspect installed components, versions, repo status, and integrations Zero privileges
--print-downloads Print official Google tarballs & repository asset URLs Zero privileges
--uninstall Cleanly remove helper-configured repositories, packages & integrations Sudo required
--no-nautilus Skip GNOME Files / Nautilus context menu integration Sudo required
--dry-run Simulate installation plan and exit 0 without making system changes Zero privileges
-h, --help Display help text, usage instructions, and examples Zero privileges

🛠️ Maintenance: Status & Clean Uninstallation

Our distribution infrastructure is designed to be transparent, auditable, and 100% reversible.

🔍 Inspect Installation Status

Check which applications, versions, repository definitions, GPG keys, and desktop extensions are active on your system (works without sudo):

curl -fsSL https://x3m-industries.github.io/antigravity-packages/install.sh | bash -s -- --status

🗑️ Clean Uninstallation

Cleanly remove packages via your native package manager (dnf or apt), purge repository definitions, remove GPG keyrings, and delete the Nautilus extension while safely preserving your personal project workspaces in ~/.config and $HOME:

curl -fsSL https://x3m-industries.github.io/antigravity-packages/install.sh | bash -s -- --uninstall

🐧 Manual Repository Setup (Without curl scripts)

Enterprise environments and security-conscious administrators can configure repositories directly using native system commands.

Fedora, RHEL, CentOS Stream, Rocky Linux, AlmaLinux (DNF / YUM)

1. Add the RPM repository file to /etc/yum.repos.d/:

sudo curl -fsSL https://x3m-industries.github.io/antigravity-packages/rpm/antigravity.repo -o /etc/yum.repos.d/antigravity.repo

2. Install the applications:

sudo dnf install antigravity-ide antigravity

3. Receive automatic updates during your normal system upgrades:

sudo dnf update antigravity-ide antigravity

Ubuntu, Debian, Linux Mint, Pop!_OS (APT)

1. Add the binary GPG keyring and modern DEB822 repository definition:

sudo mkdir -p /etc/apt/keyrings && sudo curl -fsSL https://x3m-industries.github.io/antigravity-packages/deb/antigravity.gpg -o /etc/apt/keyrings/antigravity.gpg && sudo curl -fsSL https://x3m-industries.github.io/antigravity-packages/deb/antigravity.sources -o /etc/apt/sources.list.d/antigravity.sources

2. Update index and install packages:

sudo apt update && sudo apt install antigravity-ide antigravity

3. Upgrade anytime with:

sudo apt update && sudo apt install --only-upgrade antigravity-ide antigravity

openSUSE Leap & Tumbleweed (Zypper)

1. Add repository and import the ASCII-armored GPG key:

sudo zypper addrepo -f https://x3m-industries.github.io/antigravity-packages/rpm/ antigravity && sudo rpm --import https://x3m-industries.github.io/antigravity-packages/rpm/RPM-GPG-KEY-antigravity

2. Install packages:

sudo zypper install antigravity-ide antigravity

📂 Multi-Desktop File Manager Right-Click Integration

The universal installer and native RPM/DEB packages automatically configure native context menus and right-click actions across all major Linux desktop environments:

GNOME Files (Nautilus) & MATE (Caja)

  • Right-click files or project directories: Adds "Open in Antigravity IDE".
  • Right-click directory background: Adds "Open Folder in Antigravity IDE".
  • Compatibility: Fully supports Nautilus 4.x (GNOME 43+ / GTK4), Nautilus 3.x, and Caja.
  • File locations: /usr/share/nautilus-python/extensions/open-in-antigravity-ide.py and /usr/share/caja-python/extensions/.

If the context menu does not appear immediately after installation, restart Nautilus:

nautilus -q

KDE Plasma (Dolphin)

Configured via native KIO Service Menu (/usr/share/kio/servicemenus/open-in-antigravity-ide.desktop). Right-clicking any folder or file displays "Open in Antigravity IDE" at top level with zero extra Python dependencies.

Linux Mint / Cinnamon (Nemo)

Configured via native Nemo Action (/usr/share/nemo/actions/open-in-antigravity-ide.nemo_action). Right-clicking any file or folder in Linux Mint opens it directly in Antigravity IDE.

COSMIC Desktop (Pop!_OS & COSMIC)

Full FreeDesktop MIME type integration (inode/directory, application/x-code-workspace) automatically surfaces Antigravity IDE in cosmic-files "Open With" menus and enables instant discovery in cosmic-launcher search.

🏹 Arch Linux, Manjaro & EndeavourOS

Arch Linux users can install Antigravity by converting our signed Debian packages using debtap or extracting RPMs.

Converting DEB to Arch Package via debtap

curl -fsSLO https://github.com/x3m-industries/antigravity-packages/releases/latest/download/antigravity-ide_latest_amd64.deb && debtap -u && debtap antigravity-ide_latest_amd64.deb && sudo pacman -U antigravity-ide-*.pkg.tar.zst

❓ Complete FAQ Archive

Frequently asked questions regarding architecture, packaging, sandboxing, and updates.

What is the difference between antigravity-ide and antigravity?
Google provides two distinct desktop applications for Linux:
• antigravity-ide: The official Google AI code editor based on Code OSS with application menu launchers, diff viewer, and antigravity-ide:// browser OAuth handlers.
• antigravity: Google's official Agent Hub (Antigravity 2.0) interface for configuring and orchestrating autonomous coding agents. Google's standalone terminal agent (agy) is installed separately into user-space (~/.local/bin/agy).
How do daily automated updates work?
A GitHub Actions automated cron workflow checks Google's official download CDN daily at 05:00 UTC. Whenever Google pushes a new release, packages for both x86_64 and aarch64 are built, sanitized, signed, tested in Fedora/Ubuntu containers, and deployed. You receive them via standard system updates (dnf update or apt upgrade).
Why should I use native RPM or DEB packages instead of extracting tarballs to /opt?
Basic community scripts unpack tarballs directly into /opt using custom bash loops. This bypasses your package manager, leaving files unindexed and updates manual. Our native RPM and DEB packages integrate directly with DNF, APT, and Zypper. You benefit from automatic updates, cryptographic GPG signature checks, standard dependency resolution, hardened Chromium sandboxing permissions, and clean uninstallation.
How do I update Google Antigravity IDE in Ubuntu or Debian?
Run sudo apt update && sudo apt install --only-upgrade antigravity-ide antigravity, or simply perform your regular system upgrade with sudo apt update && sudo apt upgrade.
Does this include GNOME Files (Nautilus) right-click integration?
Yes! When Antigravity IDE is installed, the installer sets up a Nautilus extension allowing you to right-click any file, directory, or empty folder background and select "Open in Antigravity IDE".
Are ARM64 / aarch64 systems supported?
Yes! Both x86_64 (Intel/AMD) and aarch64 (ARM64, Raspberry Pi 4/5 64-bit, Ampere, Apple Silicon Linux VMs) RPM and DEB packages are natively built and published for every release.
Is it safe to run the universal installer more than once?
Yes, the universal installer is completely idempotent. Running it multiple times safely refreshes repository definitions and GPG keys without creating duplicates, and upgrades your applications to the latest upstream release.
How do I check installation status or cleanly uninstall?
Run curl -fsSL https://x3m-industries.github.io/antigravity-packages/install.sh | bash -s -- --status to inspect installed components, or pass --uninstall to cleanly remove packages, repos, and extensions without touching your personal projects.
