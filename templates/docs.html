⚡ Universal Installer CLI Reference

The universal installer script (install.sh) accepts command-line parameters for unattended CI/CD automation, component selection, diagnostic inspection, and clean uninstallation.

FlagDescriptionPrivileges
-y, --yes, --non-interactiveRun silently without interactive prompts (installs IDE, Hub, CLI)Sudo required
--allExplicitly install all three components (IDE, Hub, CLI)Sudo required
--cli-onlyInstall only the Antigravity CLI (agy) in ~/.local/bin/agyUser-Space (No sudo)
--ide-onlyInstall only the Antigravity IDE (code editor) via RPM/DEBSudo required
--hub-onlyInstall only the Antigravity Hub (agent platform) via RPM/DEBSudo required
--no-cliSkip Antigravity CLI installation (desktop packages only)Sudo required
--no-ideSkip Antigravity IDE installationSudo / User
--no-hubSkip Antigravity Hub installationSudo / User
--statusInspect installed components, versions, repo status, and integrationsZero privileges
--print-downloadsPrint official Google tarballs & repository asset URLsZero privileges
--uninstallCleanly remove helper-configured repositories, packages & integrationsSudo required
--no-nautilusRemove the file manager integrations shipped with the IDE package (alias: --no-desktop-integrations)Sudo required
--dry-runSimulate installation plan and exit 0 without making system changesZero privileges
-h, --helpDisplay help text, usage instructions, and examplesZero privileges

🛠️ Maintenance: Status & Clean Uninstallation

Our distribution infrastructure is designed to be transparent, auditable, and 100% reversible.

🔍 Inspect Installation Status

Check which applications, versions, repository definitions, GPG keys, and desktop extensions are active on your system (works without sudo):

curl -fsSL https://x3m-industries.github.io/antigravity-packages/install.sh | bash -s -- --status

🗑️ Clean Uninstallation

Cleanly remove packages via your native package manager (dnf or apt), purge repository definitions, remove GPG keyrings, and delete the Nautilus extension while safely preserving your personal project workspaces in ~/.config and $HOME:

curl -fsSL https://x3m-industries.github.io/antigravity-packages/install.sh | bash -s -- --uninstall

🐧 Manual Repository Setup (Without curl scripts)

Enterprise environments and security-conscious administrators can configure repositories directly using native system commands.

🎩 Fedora, RHEL & CentOS (DNF Repository) — Antigravity Fedora DNF

1. Add the RPM repository file to /etc/yum.repos.d/:

sudo curl -fsSL https://x3m-industries.github.io/antigravity-packages/rpm/antigravity.repo -o /etc/yum.repos.d/antigravity.repo

2. Install the applications:

sudo dnf install antigravity-ide antigravity

3. Receive automatic updates during your normal system upgrades:

sudo dnf update antigravity-ide antigravity

🟠 Ubuntu, Debian, Pop!_OS & Mint (APT Repository) — Antigravity Ubuntu PPA / APT

1. Add the binary GPG keyring and modern DEB822 repository definition:

sudo mkdir -p /etc/apt/keyrings && sudo curl -fsSL https://apt.x3m.industries/deb/antigravity.gpg -o /etc/apt/keyrings/antigravity.gpg && sudo curl -fsSL https://apt.x3m.industries/deb/antigravity.sources -o /etc/apt/sources.list.d/antigravity.sources

2. Update index and install packages:

sudo apt update && sudo apt install antigravity-ide antigravity

3. Upgrade anytime with:

sudo apt update && sudo apt install --only-upgrade antigravity-ide antigravity

🦎 openSUSE Tumbleweed & Leap (Zypper Repository) — Antigravity openSUSE

1. Add repository and import the ASCII-armored GPG key:

sudo zypper addrepo -f https://x3m-industries.github.io/antigravity-packages/rpm/ antigravity && sudo rpm --import https://x3m-industries.github.io/antigravity-packages/rpm/RPM-GPG-KEY-antigravity

2. Install packages:

sudo zypper install antigravity-ide antigravity

📂 Multi-Desktop File Manager Right-Click Integration

The universal installer and native RPM/DEB packages automatically configure native context menus and right-click actions across all major Linux desktop environments:

GNOME Files (Nautilus) & MATE (Caja)

  • Right-click files or project directories: Adds "Open in Antigravity IDE".
  • Right-click directory background: Adds "Open Folder in Antigravity IDE".
  • Compatibility: Fully supports Nautilus 4.x (GNOME 43+ / GTK4), Nautilus 3.x, and Caja.
  • File locations: /usr/share/nautilus-python/extensions/open-in-antigravity-ide.py and /usr/share/caja-python/extensions/.

If the context menu does not appear immediately after installation, restart Nautilus:

nautilus -q

KDE Plasma (Dolphin)

Configured via native KIO Service Menu (/usr/share/kio/servicemenus/open-in-antigravity-ide.desktop). Right-clicking any folder or file displays "Open in Antigravity IDE" at top level with zero extra Python dependencies.

Linux Mint / Cinnamon (Nemo)

Configured via native Nemo Action (/usr/share/nemo/actions/open-in-antigravity-ide.nemo_action). Right-clicking any file or folder in Linux Mint opens it directly in Antigravity IDE.

COSMIC Desktop (Pop!_OS & COSMIC)

Full FreeDesktop MIME type integration (inode/directory, application/x-code-workspace) automatically surfaces Antigravity IDE in cosmic-files "Open With" menus and enables instant discovery in cosmic-launcher search.

🏹 Arch Linux, Manjaro & EndeavourOS — Antigravity Arch Linux

Arch Linux users can install Antigravity by converting our signed Debian packages using debtap or extracting RPMs.

Converting DEB to Arch Package via debtap

curl -fsSLO https://github.com/x3m-industries/antigravity-packages/releases/latest/download/antigravity-ide_latest_amd64.deb && debtap -u && debtap antigravity-ide_latest_amd64.deb && sudo pacman -U antigravity-ide-*.pkg.tar.zst

🛠️ Troubleshooting & High-Impact Fixes

Diagnose and resolve common Linux runtime issues, sandboxing permission errors, and browser authentication redirects.

Ubuntu 24.04+ SUID Sandbox Error (The SUID sandbox helper binary was found...)

Starting with Ubuntu 24.04 (Noble Numbat), the Linux kernel blocks unprivileged user namespaces via AppArmor. Raw tarballs extracted into /opt crash with The SUID sandbox helper binary was found, but is not configured properly. Our native .deb and .rpm packages automatically set hardened SUID permissions (04755 root:root) during package installation. If fixing an existing manual extraction:

sudo chown root:root /usr/share/antigravity-ide/chrome-sandbox && sudo chmod 4755 /usr/share/antigravity-ide/chrome-sandbox

Google OAuth Browser Redirects Failing (antigravity-ide:// and antigravity://)

When logging into your Google account, your browser redirects to an antigravity-ide:// URI callback. If this handler is unregistered, login fails silently. Our packages register these automatically. To verify or manually register with FreeDesktop:

xdg-mime default antigravity-ide-url-handler.desktop x-scheme-handler/antigravity-ide && xdg-mime default antigravity.desktop x-scheme-handler/antigravity

Updating Applications to the Latest Release

To upgrade your installed Antigravity packages via your system package manager:

# Fedora / RHEL / Rocky (DNF): sudo dnf update antigravity-ide antigravity # Ubuntu / Debian (APT): sudo apt update && sudo apt install --only-upgrade antigravity-ide antigravity # openSUSE (Zypper): sudo zypper update antigravity-ide antigravity

❓ Complete FAQ Archive

Frequently asked questions regarding architecture, packaging, sandboxing, and updates.

What is the difference between antigravity-ide and antigravity?
Google provides two distinct desktop applications for Linux:
• antigravity-ide: The official Google AI code editor based on Code OSS with application menu launchers, diff viewer, and antigravity-ide:// browser OAuth handlers.
• antigravity: Google's official Agent Hub (Antigravity 2.0) interface for configuring and orchestrating autonomous coding agents. Google's standalone terminal agent (agy) is installed separately into user-space (~/.local/bin/agy).
How do daily automated updates work?
A GitHub Actions automated cron workflow checks Google's official download CDN daily at 05:00 UTC. Whenever Google pushes a new release, packages for both x86_64 and aarch64 are built, sanitized, signed, tested in Fedora/Ubuntu containers, and deployed. You receive them via standard system updates (dnf update or apt upgrade).
Why should I use native RPM or DEB packages instead of extracting tarballs to /opt?
Manual tutorials often instruct users to unpack Google tarballs into /opt/antigravity. While this seems simple initially, it creates severe real-world problems:
• Broken In-App Auto-Updates: Because /opt is owned by root, Electron's unprivileged auto-updater fails silently with permission errors, trapping you in manual update cycles.
• Missing High-Res Icons: Google bundles the Hub's icon inside app.asar. Manual installers get stuck with generic desktop gear icons. Our packages dynamically parse the ASAR header and register native 512x512 icons.
• Broken Google OAuth Logins: Manual desktop files omit URL protocol handlers (antigravity:// and antigravity-ide://), causing browser login redirects to fail.
• Hardened Chromium Sandboxing: Ubuntu 24.04+ restricts unprivileged user namespaces via AppArmor. Without hardened 4755 root:root permissions on chrome-sandbox, Electron apps crash.
• Package Manager Integration: Native RPM & DEB packages update seamlessly via apt upgrade or dnf update, verify GPG signatures, resolve shared libraries, and uninstall cleanly without orphaned files.
How do I update Google Antigravity IDE in Ubuntu or Debian?
Run sudo apt update && sudo apt install --only-upgrade antigravity-ide antigravity, or simply perform your regular system upgrade with sudo apt update && sudo apt upgrade.
Does this include GNOME Files (Nautilus) right-click integration?
Yes! When Antigravity IDE is installed, the installer sets up a Nautilus extension allowing you to right-click any file, directory, or empty folder background and select "Open in Antigravity IDE".
Are ARM64 / aarch64 systems supported?
Yes! Both x86_64 (Intel/AMD) and aarch64 (ARM64, Raspberry Pi 4/5 64-bit, Ampere, Apple Silicon Linux VMs) RPM and DEB packages are natively built and published for every release.
Is it safe to run the universal installer more than once?
Yes, the universal installer is completely idempotent. Running it multiple times safely refreshes repository definitions and GPG keys without creating duplicates, and upgrades your applications to the latest upstream release.
How do I check installation status or cleanly uninstall?
Run curl -fsSL https://x3m-industries.github.io/antigravity-packages/install.sh | bash -s -- --status to inspect installed components, or pass --uninstall to cleanly remove packages, repos, and extensions without touching your personal projects.
How do I fix the 'chrome-sandbox SUID' or permission error on Ubuntu 24.04?
Ubuntu 24.04 Noble Numbat and hardened Linux kernels restrict unprivileged user namespaces via AppArmor. When extracting raw tarballs, Electron crashes with The SUID sandbox helper binary was found, but is not configured properly. Our native .deb and .rpm packages automatically configure hardened 04755 root:root permissions on chrome-sandbox during package installation, completely preventing this issue.
How do I fix Google login or browser OAuth redirect (antigravity-ide://) not opening?
Google login redirects use custom URL protocol schemes (antigravity-ide:// and antigravity://). When tarballs are extracted manually without desktop protocol handler registration, browsers fail to hand the authentication token back to the editor. Our packages automatically register FreeDesktop URL handlers via /usr/share/applications/antigravity-ide-url-handler.desktop so browser OAuth login redirects complete seamlessly.
How do I install Google Antigravity on Fedora using DNF?
To configure the Antigravity Fedora DNF repository, add our official repository file: sudo curl -fsSL https://x3m-industries.github.io/antigravity-packages/rpm/antigravity.repo -o /etc/yum.repos.d/antigravity.repo and run sudo dnf install antigravity-ide antigravity. Works seamlessly on Fedora 38, 39, 40+, RHEL 8/9, CentOS Stream, Rocky Linux, and AlmaLinux.

For Ubuntu 22.04 LTS (Jammy), 24.04 LTS (Noble), Debian 11/12, Pop!_OS, and Linux Mint, add our signed GPG keyring and modern DEB822 source file: sudo mkdir -p /etc/apt/keyrings && sudo curl -fsSL https://apt.x3m.industries/deb/antigravity.gpg -o /etc/apt/keyrings/antigravity.gpg && sudo curl -fsSL https://apt.x3m.industries/deb/antigravity.sources -o /etc/apt/sources.list.d/antigravity.sources. Then run sudo apt update && sudo apt install antigravity-ide antigravity.

On openSUSE Tumbleweed and Leap 15.5+, add the repository and import the ASCII-armored GPG key: sudo zypper addrepo -f https://x3m-industries.github.io/antigravity-packages/rpm/ antigravity && sudo rpm --import https://x3m-industries.github.io/antigravity-packages/rpm/RPM-GPG-KEY-antigravity.
